# models/

**このディレクトリの中身はコミットしない**（`.gitignore` で除外している）。

現行の布石方策モデルは dlshogi with GCT (WCSC31) の学習済み重みを転移して追加学習した
派生物であり、**再配布の許諾が存在しない**。このリポジトリは公開なので、ここに重みを
置いてコミットすると、そのまま再配布に当たる。

手元での動作確認には、`fuseki-shogi-ai`（非公開の開発用リポジトリ）側にある
`models/fuseki_rollout_iter38.onnx` をこのディレクトリへコピーして使う。
私的利用の範囲であり、公開デプロイに載せなければ問題にならない。

公開版に載せるモデルは、GCT由来のパラメータを含まない新しい布石専用ネットに
置き換える。置き換えの計画は開発用リポジトリの `docs/degct_plan.md` にある。
